# Code of Conduct


## Scope

This code applies to Issues, pull requests, reviews, Discussions, and other public collaboration around this repository.

## Expected conduct

Communicate professionally and respectfully. Critique claims, contracts, code, artifacts, and methods rather than people. Protect private information, respect attribution and third-party rights, and keep uncertainty explicit. Harassment, discrimination, threats, doxxing, impersonation, fabricated evidence, deliberate deception, and repeated disruption are unacceptable.

### 文档产物的诚信审查 / Artifact integrity in collaboration

中文：公开讨论文档自动生成与 Agent 协作时，明确标注输入、生成结果、实际审计和未验证解释，不以生成成功、漂亮图表或有效 JSON 伪装成来源可信或独立科学复现

English: Public discussion of automated documents and agent contributions distinguishes inputs, generated artifacts, executed audits and unverified interpretations. Generation success, polished figures or valid JSON is not source trust or independent scientific reproduction

## Evidence-aware collaboration

Keep implementation behavior, structural validation, scientific validity, external standards, proposals, and unknown state distinct. Do not present unexecuted checks as passed or silently rewrite historical maintenance records to match later knowledge.

## Sensitive information

Do not publish credentials, private data, or unpublished exploit details. Follow `SECURITY.md` for security-sensitive reports. Conduct concerns containing private information should use an available private contact route rather than a public Issue.

## Moderation

The repository maintainer may edit, hide, remove, lock, or reject contributions that violate these standards or materially undermine repository integrity. Repeated or serious violations may result in participation restrictions.

The repository owner retains final moderation and merge authority.

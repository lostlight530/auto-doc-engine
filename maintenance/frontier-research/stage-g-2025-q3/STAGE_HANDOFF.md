# Frontier Research Stage Handoff — Stage G / 2025-Q3

## Eligible findings
- software metadata increasingly benefits from typed source/application, role, and review relationships;
- publication mutability is a distinct artifact-state property;
- signed provenance/attestation belongs to artifact identity but does not inherit correctness or scientific validity;
- converter AST serialization can be a first-class structural evidence surface;
- converter revision remains part of transformation provenance.

## Unsafe generalization
- metadata relation => verified real-world relation;
- review metadata => peer-review validity;
- immutable release => correct or secure software;
- attestation => scientific truth;
- XML AST => original-byte preservation or semantic equivalence;
- release note => local execution evidence.

```text
handoff != authority transfer
identity != truth
attestation != validation
structural representation != semantic equivalence
```

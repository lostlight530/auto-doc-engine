## 2024 synthesis
The year moves from file-centered reasoning toward an evidence envelope for artifact generation:

```text
source object
-> representation / derivative family
-> transformation state
-> dependency intent
-> resolution / lock state
-> runtime + platform
-> converter / renderer revision
-> options + environment-derived configuration
-> execution
```

This chain is not a mandatory universal schema. It is a non-collapse model: fields become relevant when they materially affect the artifact or the claim being made about it.

## What strengthened across the year
1. Artifact identity is not exhausted by filename or hash.
2. Lineage records relations but does not inherit truth.
3. Version/default/configuration changes can alter derivative semantics without source changes.
4. Environment declarations and resolved/installed/executed environments are separate.
5. Provenance and attestations strengthen origin/process evidence while leaving semantic/scientific validity open.
6. Later corrections/releases move interpretation forward without deleting earlier artifact identity or lifecycle state.

## Timeline and turning points
### 2026-Q1
- 2026-02-04 / pandoc 3.9: Pandoc 3.9 announces a WASM build and browser application, JSON/YAML defaults with variable interpolation, and media-archive output options. Research inference: Execution host (browser versus native binary), defaults-file version and configuration become distinct transformation provenance; browser availability does not prove identical results.
- 2026-03-19 / pandoc 3.9.0.2: Pandoc 3.9.0.2 is explicitly a fix for a regression in the Typst template introduced in an earlier 3.9 patch sequence. Research inference: A patch-release boundary can affect the rendered derivative even when source content is unchanged.
- Explicit negative-space months: 2026-01 — not evidence of no global events.

### 2026-Q2
- 2026-06-02 / specification 1.7.1: CycloneDX 1.7.1 adds ModelCard.property in Protobuf and modelCard properties/consideration cardinality alignments in XML and adds matching tests. Research inference: Serializations of ostensibly one evidence object have versioned schema behavior; version and format need distinct identity.
- 2026-06-04 / pandoc 3.10: Pandoc 3.10 adds --typst-input to pass sys.inputs parameters and changes the default ms PDF engine to groff; ODT style emission also changes. Research inference: Transformation receipts should distinguish explicit parameters, inferred defaults and output writer/backend revision.
- Explicit negative-space months: 2026-04, 2026-05 — not evidence of no global events.

### 2026-Q3
- 2026-07-22 / pandoc 3.10.1: Pandoc 3.10.1 is a follow-up release with incremental improvements and bug fixes after 3.10. Research inference: Patch chronology is provenance: a durable artifact record should name the revision rather than only 'Pandoc 3.10'.
- 2026-08-29 / pandoc 3.11: Pandoc 3.11 introduces --math-method, changes the default to mathml, retains deprecated aliases and reports a security-related template-fetch fix. Research inference: Math rendering policy, config aliases and fetching/source trust can change independently of source text.
- 2026-09-17 / specification 1.7.2: CycloneDX 1.7.2 adds an optional repeated XML node for relatedCryptographicAsset and introduces schema tests. Research inference: Evidence portability depends on schema revision and serialization-specific relations; a BOM can encode claims without verifying them.
- 2026-09-29 / pandoc 3.12: Pandoc 3.12 reports performance-oriented changes and makes -t xml respect --standalone, emitting a fragment when absent. Research inference: Latency claims and output framing are separate transformation evidence; an output structure change can affect derivative identity.

### 2026-Q4 OPEN, as of October 19
- 2026-10-08 / pandoc 3.12.1: Pandoc 3.12.1 adds FODT input/output and changes citeproc interpretation of structured surname particles, alongside several regression fixes. Research interpretation: A citation-provenance path depends on a named converter revision and reference semantics; apparently identical data may yield different derivative citations.
- 2026-10-09 / uv 0.13.0: uv 0.13.0 announces Python 3.15 as its default stable Python, together with correctness and compatibility changes. Research interpretation: Environment resolution defaults are another independent clock for reproducible document generation; lock representation does not establish the realized interpreter.

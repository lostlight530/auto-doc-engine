# E3 — Release State and Q1 Non-Release Boundary

## Research question
Can a documented release process or active milestone be treated as publication during the quarter?

## Evidence
RO-Crate's official release history shows RO-Crate 1.2.0 was tagged on 2025-04-28 and the specification lists publication date 2025-06-04 with Recommendation status.

Source: https://github.com/ResearchObject/ro-crate/releases

These dates are after the Stage E window ending 2025-03-31.

## Retrospective interpretation
The later official release record is used only to bound the earlier state:

```text
Q1 release work / milestone
!= Q1 Recommendation publication

later Q2 release
!= retroactive Q1 release
```

This is negative-space evidence about publication state, not a claim that no work occurred during Q1.

## Limits
The Stage did not reconstruct every milestone issue or every draft revision. It only establishes that the official 1.2.0 release/publication dates are outside Q1.

## Outcome
`SUPPORTED_TEMPORAL_BOUNDARY`

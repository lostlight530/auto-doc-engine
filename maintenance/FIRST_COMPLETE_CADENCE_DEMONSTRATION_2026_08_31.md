## 1. Daily demonstration

Command

```bash
python core/maintenance_cadence.py daily --as-of 2026-08-31
```

Daily is intended to answer

```text
Are current canonical files present
Did a project-owned decorative profile version reappear
Did forbidden GitHub-governance architecture appear
Is Manifest calibration stale for the daily horizon
Did a demonstrated local artifact/document contract drift occur
```

Daily deliberately does **not** request canonical hashes or history inventory

Expected structural shape

```text
cadence: daily
period_status.calendar_month: calendar-month-close
period_status.stage: closed
baseline_sha256: {}
history_snapshots: []
```

Do not infer

```text
no finding -> scientific correctness
current docs aligned -> source credibility
calendar close -> reproduction
```

## 2. Weekly demonstration

Command

```bash
python core/maintenance_cadence.py weekly --as-of 2026-08-31
```

Weekly adds cross-document and cross-contract reconciliation

Review together

```text
implementation
↔ Manifest
↔ Research Contract
↔ artifact record / lineage contracts
↔ process and assertion-basis contracts
↔ README / Architecture
↔ Agent / Contributor guidance
↔ Frontier Alignment
↔ cross-repository profile names
```

Weekly additionally requests

```text
canonical SHA-256 baseline
historical snapshot inventory
```

When all configured canonical files exist, the baseline can contain up to **22 canonical file hashes**
Those hashes must be generated by the scanner and must not be copied from this demonstration

Historical inventory is pattern-driven and includes matching `*_DAY_CONSOLIDATION.md` and `STAGE_*.md` files without rewriting them

Interpretation

```text
hash = byte identity under SHA-256
hash != semantic equivalence
history inventory != deprecation decision
weekly consistency != proof of correctness
```
